# Apple Seed Brain — local vision

The Brain can accept a panic/log photo and send it to a **local** Ollama vision model on the same computer. No OpenAI/remote AI API is used by this feature.

Default model: `qwen3-vl:4b` (change with `APPLE_SEED_VISION_MODEL`).

Use `start_vision.bat` to pull the configured model and start the local Brain server.
